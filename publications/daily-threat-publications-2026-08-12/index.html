Critical Vulnerabilities Patched: SonicWall, VMware, Metabase, and Cisco Flaws Addressed

August 12, 2026
11 articles (5 new, 6 updated)

Summary

This daily summary highlights critical security updates and new vulnerabilities impacting various software and hardware. SonicWall zero-days (CVE-2026-15409, CVE-2026-15410) are now being actively exploited for ransomware deployment, escalating their threat level. VMware has patched a critical VM escape flaw (CVE-2026-47876) in ESXi, with active exploitation confirmed for CVE-2026-59310, allowing persistent reverse SSH tunnels. The Metabase zero-day SQL injection vulnerability (CVE-2026-72898) continues widespread exploitation, with LexisNexis confirming an incident. Microsoft's August Patch Tuesday addresses over 400 vulnerabilities, including a Windows privilege escalation zero-day (CVE-2026-68820) exploited by the Lazarus Group.

CISA warns of Gunra ransomware targeting critical infrastructure, utilizing vulnerabilities in Fortinet and Schneider Electric devices, with new TTPs including session hijacking and MFA bypass. A LiteLLM AI supply chain attack by Team PCP exposed over 2,500 companies through a novel secondary exfiltration technique using GitHub repositories. New threats include 'Ghostjacking' and 'GhostSplice' attacks targeting AI agents, and AI-powered cyberattacks impacting major U.S. corporations. Cisco has patched a zero-day DoS vulnerability in its Secure Firewall (CVE-2026-20349). Zoom has addressed a zero-click RCE flaw in its conferencing app, and Ivanti has released patches for critical RCE vulnerabilities in its Endpoint Manager.

Organizations are strongly advised to apply all available patches and review security configurations to mitigate these evolving threats.

VMware Patches Critical VM Escape Flaw (CVE-2026-47876) in ESXi

CRITICAL

VMware Patches Critical ESXi VM Escape Vulnerability

Update:

Following the initial advisory, security researchers have observed widespread scanning activity targeting VMware vCenter Server instances for CVE-2026-59309, indicating imminent mass exploitation. More critically, CVE-2026-59310 is now confirmed to be actively exploited in the wild. Attackers are leveraging this flaw to write malicious cron jobs that establish persistent reverse SSH tunnels using the `reverse_ssh` tool, compromising over 360 unique IP addresses globally. Organizations must prioritize patching and hunt for compromise using the newly identified IOCs, including `reverse_ssh` file presence and outbound SSH traffic from vCenter.

CISA Warns of Gunra RaaS Targeting Critical Infrastructure

HIGH

CISA Issues Alert on Gunra Ransomware Targeting Global Sectors

Update:

The updated advisory from CISA, FBI, NSA, DC3, USSS, and KNPA provides critical new details on Gunra ransomware. It specifically identifies vulnerabilities in Fortinet FortiOS/FortiProxy and Schneider Electric PowerLogic (CVE-2024-5559) as initial access vectors. New TTPs include session hijacking via SSL-VPN manipulation, MFA bypass through VDI portal tampering, and lateral movement using PsExec/WMIC. The group also employs defense evasion by deleting logs and demands multi-million dollar ransoms. New hunting hints include specific URL patterns, process names, and log analysis for these advanced tactics.

Update:

LiteLLM AI Supply Chain Attack Exposes 2,500+ Companies

CRITICAL

LiteLLM Supply Chain Attack Harvests Credentials from 2,500 Firms

Update:

The attack, attributed to Team PCP, utilized a sophisticated secondary exfiltration technique. If direct outbound connections were blocked, the malware would leverage the victim's own GitHub credentials to create a new public repository. Stolen secrets were then uploaded as release assets to this repository, making the exfiltrated data appear as legitimate activity and publicly exposing sensitive information. This method highlights the advanced nature of the threat and the critical need for auditing source control activity.
