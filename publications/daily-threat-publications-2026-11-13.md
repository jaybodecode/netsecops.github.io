# GitHub Attack Escalates, Microsoft 365 Outage, New Ransomware & Zero-Day

**Published:** 2026-11-13 | **Articles:** 7

**Supply Chain & Cloud Incidents:**

*   **Massive GitHub Supply Chain Attack Injects 'wfx' Stealer:** The 'wfx-loot' campaign has compromised over 4,800 GitHub accounts, impacting 1,835 repositories, including those of major companies and government entities. Attackers are now stealing OIDC tokens and cloud credentials, using new reconnaissance techniques and exfiltrating data via Telegram. The compromise has extended to a Packagist package and a Go module.
*   **Widespread Microsoft 365 Outage Hits Millions:** A global outage on November 12, 2026, disrupted Microsoft 365 services like Outlook, Teams, and Copilot for over 24 hours. The incident, caused by cascading server health check failures, was confirmed as not a cyberattack, with Microsoft working to restore services.
*   **Belarusian Cloud Provider ActiveCloud Hit by Ransomware:** ActiveCloud experienced a significant ransomware attack on November 10, 2026, leading to widespread outages for its customers. The attack encrypted cloud infrastructure, impacting virtual servers, corporate email, and customer support systems for businesses in Belarus and Russia.

**Critical Vulnerabilities & New Threats:**

*   **Unpatched 'SignDrop' Windows Zero-Day Allows SYSTEM Privilege Escalation:** A newly disclosed zero-day vulnerability, 'SignDrop,' in the Windows Common Log File System (CLFS) allows local attackers to escalate privileges to SYSTEM. The exploit leverages a previously implemented security mitigation, and a proof-of-concept is available for recent Windows versions.
*   **Critical Flaws in Red Hat Quay Enable Full Registry and Supply Chain Attack:** Two critical vulnerabilities (CVE-2026-123710 and CVE-2026-110697) in Red Hat Quay allow for full supply chain compromise by injecting malicious container images. These flaws enable unauthenticated attackers to gain read/write access or low-privileged users to manipulate images across tenants.
*   **'Neutrino' Ransomware Discovered Using Double-Extortion Tactics:** A new ransomware family, 'Neutrino,' employs double-extortion by encrypting files and exfiltrating sensitive data. Attackers threaten to leak stolen information if the ransom is not paid, increasing pressure on victims.

**Advanced Cyber Espionage:**

*   **China-Nexus Group Uses Autonomous AI Framework for Cyber Espionage:** A China-nexus threat actor utilized an AI penetration testing framework, Cairn, with large language models to conduct autonomous cyber espionage. Between August and September 2026, the group targeted organizations in the semiconductor, defense, and civil society sectors, automating reconnaissance, exploitation, and data retrieval.

## Articles in this publication
- [Massive GitHub Supply Chain Attack Injects 'wfx' Stealer into Repos](https://cyber.netsecops.io/articles/github-supply-chain-attack-wfx-stealer-targets-ci-cd-secrets/) (critical)
  A large-scale software supply chain attack is actively targeting the GitHub ecosystem. Attackers are using compromised developer accounts to inject a sophisticated information stealer, dubbed 'wfx', into tens of thousands of code repositories. The malware is designed to run within GitHub Actions to exfiltrate sensitive CI/CD secrets, including repository secrets, cloud credentials, and API keys, posing a severe threat to software development and deployment pipelines.
- [Widespread Microsoft 365 Outage Hits Millions of Users Globally](https://cyber.netsecops.io/articles/microsoft-365-outage-disrupts-outlook-teams-and-copilot-worldwide/) (high)
  A significant global outage struck Microsoft 365 services on November 12, 2026, affecting Outlook, Teams, SharePoint, and Copilot. The disruption, which lasted for over 24 hours for some users, was caused by a large number of servers failing health checks, leading to a cascading failure across the infrastructure. Microsoft confirmed the incident was not a cyberattack and worked to restore services by restarting servers and rerouting traffic, though intermittent issues persisted as a massive email backlog was processed.
- [Belarusian Cloud Provider ActiveCloud Hit by Disruptive Ransomware Attack](https://cyber.netsecops.io/articles/belarusian-cloud-provider-activecloud-hit-by-disruptive-ransomware-attack/) (high)
  Belarusian cloud provider ActiveCloud suffered a major ransomware attack on November 10, 2026, causing widespread outages for its customers. The attack encrypted parts of the company's cloud infrastructure, taking down its own website, customer support systems, and client services including virtual servers and corporate email. The disruption affected numerous businesses in Belarus and Russia, including news outlets and e-commerce sites. ActiveCloud worked for several days to restore its infrastructure and customer environments.
- [Unpatched 'SignDrop' Windows Zero-Day Allows SYSTEM Privilege Escalation](https://cyber.netsecops.io/articles/unpatched-signdrop-windows-zero-day-allows-system-privilege-escalation/) (critical)
  A security researcher has publicly disclosed 'SignDrop,' an unpatched zero-day vulnerability in the Windows Common Log File System (CLFS). The flaw allows a local attacker to escalate privileges to NT AUTHORITY\SYSTEM. The exploit cleverly abuses a security mitigation Microsoft introduced in 2025 to harden CLFS, turning the defense mechanism into an attack vector. A proof-of-concept exploit has been released on GitHub, affecting recent versions of Windows 11 and Windows Server 2025. Microsoft has not yet assigned a CVE or released a patch.
- ['Neutrino' Ransomware Discovered Using Double-Extortion Tactics](https://cyber.netsecops.io/articles/neutrino-ransomware-discovered-using-double-extortion-tactics/) (high)
  Security researchers have identified a new ransomware family named 'Neutrino.' This malware follows the double-extortion trend, where it not only encrypts a victim's files—appending a '.neutrino' extension—but also claims to have exfiltrated sensitive data before encryption. The attackers leave a ransom note, 'README-RECOVERY.txt,' threatening to leak the stolen data if the ransom is not paid. This tactic is designed to increase pressure on victims to pay, even if they have viable backups.
- [Critical Flaws in Red Hat Quay Enable Full Registry and Supply Chain Attack](https://cyber.netsecops.io/articles/critical-flaws-in-red-hat-quay-enable-full-registry-and-supply-chain-attack/) (critical)
  Red Hat has patched two critical vulnerabilities in its Quay container registry, CVE-2026-123710 (CVSS 9.8) and CVE-2026-110697 (CVSS 9.9). These flaws could allow an attacker to achieve a full supply chain compromise by injecting malicious container images. The vulnerabilities enable an unauthenticated attacker to gain read/write access to any repository or a low-privileged user to steal tokens and manipulate images across tenants. All users of Quay 3 and 5 are urged to patch immediately.
- [China-Nexus Group Uses Autonomous AI Framework for Cyber Espionage](https://cyber.netsecops.io/articles/china-nexus-actors-use-autonomous-ai-to-target-semiconductor-defense-and-civil-society/) (high)
  Between August and September 2026, a China-nexus threat actor tracked as CL-STA-1238 conducted a sophisticated campaign using an open-source AI penetration testing framework called Cairn. The attackers targeted at least 19 organizations across the semiconductor, defense, and civil society sectors in 25 distinct, autonomous operations. By weaponizing Cairn with large language models like Zhipu GLM and DeepSeek, the actor was able to automate reconnaissance, exploitation, and data retrieval, successfully breaching at least 10 of the targeted entities. This activity represents a significant evolution in cyber operations, leveraging autonomous agents for intelligence collection with minimal human intervention.
