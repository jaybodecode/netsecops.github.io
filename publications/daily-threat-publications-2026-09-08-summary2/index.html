North Korean Hackers Implant Backdoor Directly into HAProxy Source Code

A North Korea-linked threat actor has been observed targeting South Korean automotive and media companies with a novel Linux toolkit. The campaign's most sophisticated element is a backdoor, dubbed 'ted backdoor,' which is compiled directly into the source code of the widely-used HAProxy load-balancing software. By integrating as a custom plugin using HAProxy's native APIs, the implant evades traditional detection methods while intercepting HTTP traffic, executing commands, and harvesting credentials. The broader toolkit also includes trojanized versions of common Linux daemons like crond and sshd, enabling long-term persistence and surveillance within compromised networks.

'BigBear 2.0' Phishing Service Bypasses MFA in Global M365 Campaign

A large-scale phishing-as-a-service (PhaaS) operation, named 'BigBear 2.0,' is targeting hundreds of organizations globally with Microsoft 365 credential theft attacks. Researched by CloudSEK, the service uses a customized version of the Evilginx2 adversary-in-the-middle (AiTM) framework to bypass multi-factor authentication (MFA) and steal session cookies. The operation, managed by an actor named 'General Boss,' has compromised over 5,000 records across 40+ countries. The framework uses advanced techniques like custom JavaScript to disable FIDO2/WebAuthn and residential proxies to evade detection. IT service providers and MSPs are primary targets, indicating a potential for supply chain attacks.

Fragmented Federal Rules Divert Resources from Cyber Incident Response

A joint report by Auburn University’s McCrary Institute and the U.S. Chamber of Commerce warns that the current landscape of federal cyber incident reporting in the United States is dangerously fragmented. The report identifies 117 different regulations across 27 federal agencies, creating duplicative and conflicting burdens on private industry during a crisis. This forces organizations to divert critical personnel and resources away from active incident response to focus on compliance paperwork. The report advocates for a streamlined 'report once, use many times' model, anchored by CISA, to harmonize requirements and allow companies to focus on defense and recovery.

Researcher 'Nightmare Eclipse' Drops Three LPE Zero-Day Exploits

Update:This update provides a deeper technical analysis of the 'FalconFlank' local privilege escalation vulnerability affecting CrowdStrike Falcon Sensor. It details the exploit's mechanism, mapping it to MITRE ATT&CK techniques such as T1068 (Privilege Escalation) and T1548.002 (Bypass UAC). New hunting hints are included, focusing on monitoring `CSFalconService.exe` for unexpected DLL loads from non-standard paths, file writes to `C:\Windows\Temp\`, and unusual child processes (Event ID 4688). The interim mitigation remains disabling the 'Office malicious macros remediation' policy.

N-able N-central Hit by Actively Exploited CVSS 10.0 RCE Flaw

Update:Further analysis of the N-able N-central RCE (CVE-2026-86218) reveals that active exploitation was observed by Huntress labs targeting the platform's API as early as September 4, 2026. N-able has also identified scanning and exploitation activity originating from the IP range 23.234.64.0/18. This new information provides critical Indicators of Compromise (IOCs) for defenders to scan their logs and network traffic. Additionally, the report maps observed and inferred attacker techniques to MITRE ATT&CK, including T1190 (Exploit Public-Facing Application) for initial access and T1078.001 (Default Accounts) for persistence, offering a clearer picture of the attack methodology.

Unpatched 'StyleSmuggler' RCE Flaw Hits Magento & Adobe Commerce

Update:Adobe has released an emergency security update for the 'StyleSmuggler' RCE zero-day, now officially tracked as CVE-2026-75650 with a critical CVSS score of 10.0. The patch addresses the unauthenticated remote code execution vulnerability affecting Adobe Commerce and Magento Open Source. Exploitation, which began on September 4, 2026, has been observed originating from IP addresses in China and Romania. Administrators are strongly advised to apply the patch immediately to mitigate the risk of compromise and to investigate for signs of active exploitation.

MikroTik Routers Hijacked via 'MikroTrick' Unauthenticated Exploit

Update:This update provides a deeper technical analysis of the 'MikroTrick' exploit chain, detailing how the privilege escalation (CVE-2026-86060) manipulates the RouterOS policy mask for full admin rights. It also maps the attack to MITRE ATT&CK techniques, including Initial Access (T1190), Privilege Escalation (T1068), Persistence (T1136.001), and Defense Evasion (T1070.006). New 'Cyber Observables' offer specific hunting hints for compromise detection, such as auditing user accounts, log analysis for '/system script add', and suspicious DNS requests. Additionally, 'IP Allowlisting' for SSH access is recommended as an enhanced mitigation, and factory reset is emphasized for suspected compromises.
