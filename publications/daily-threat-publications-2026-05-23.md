# Active Zero-Day Exploits Target Microsoft Defender & Windows; Widespread Supply Chain Attacks Hit Open-Source Ecosystems

**Published:** 2026-05-23 | **Articles:** 10

This week's cybersecurity landscape is dominated by the active exploitation of critical zero-day vulnerabilities in Microsoft products, including two in Defender and a new unpatched flaw in Windows dubbed 'MiniPlasma'. Concurrently, multiple sophisticated supply chain attacks have compromised hundreds of open-source packages across npm, PyPI, and Packagist, deploying credential-stealing worms and malware. New ransomware strains like 'Aur0ra' are emerging with dual-extortion tactics, while Iran-linked APTs escalate espionage campaigns, highlighting a period of heightened risk across software supply chains, endpoint security, and critical infrastructure.

## Articles in this publication
- [New 'MiniPlasma' Windows Zero-Day Resurrects Patched Flaw for Full System Control](https://cyber.netsecops.io/articles/miniplasma-windows-zero-day-revives-patched-flaw-for-system-privilege-escalation/) (critical)
  A security researcher has released a proof-of-concept exploit for 'MiniPlasma,' an unpatched zero-day vulnerability affecting modern Windows 11 systems. The flaw, a regression of a bug Microsoft supposedly fixed in 2020, allows a local attacker to escalate privileges to SYSTEM, gaining complete control over the machine. The vulnerability exists in the Windows Cloud Files Mini Filter Driver (`cldflt.sys`) and highlights potential gaps in Microsoft's patching process, as the original exploit for CVE-2020-17103 now works again on fully updated systems.
- [Microsoft and FBI Takedown 'Fox Tempest' Malware-Signing Service Fueling Ransomware Attacks](https://cyber.netsecops.io/articles/microsoft-dismantles-fox-tempest-malware-signing-as-a-service-platform/) (high)
  Microsoft's Digital Crimes Unit, in collaboration with the FBI and Europol, has dismantled a major cybercrime operation known as Fox Tempest. The group operated a Malware-Signing-as-a-Service (MSaaS) platform called 'signspace.cloud,' which provided threat actors, including the operators of Qilin, Akira, and Rhysida ransomware, with fraudulently obtained code-signing certificates. This service allowed malicious software to appear legitimate, bypassing security measures and enabling attacks on thousands of organizations worldwide, including hospitals, schools, and other critical infrastructure. The takedown involved seizing the platform's infrastructure and revoking associated certificates, marking a significant disruption to the cybercrime supply chain.
- [Massive HIPAA Breach Wave Hits U.S. Healthcare, Exposing Thousands of Patient Records](https://cyber.netsecops.io/articles/hipaa-data-breaches-expose-patient-data-across-multiple-us-healthcare-entities/) (high)
  Multiple U.S. healthcare organizations, including the World Trade Center Health Program and LHC Group, have disclosed significant data breaches throughout May 2026. These incidents, some orchestrated by ransomware groups like TridentLocker, have resulted in the exposure of highly sensitive Protected Health Information (PHI) for thousands of individuals. The attacks highlight a persistent and troubling trend of cybercriminals targeting the healthcare sector and its third-party vendors, compromising names, Social Security numbers, and detailed medical histories. The breaches underscore the critical need for robust security measures and diligent vendor risk management within the healthcare industry.
- [New 'Aur0ra' Ransomware Emerges with Stealthy Dual-Extortion Tactics](https://cyber.netsecops.io/articles/new-aur0ra-ransomware-employs-dual-extortion-without-renaming-files/) (high)
  A new ransomware strain named Aur0ra has been identified, employing a dual-extortion model that is becoming standard for modern ransomware. The malware encrypts files, making them inaccessible, and claims to have exfiltrated sensitive data before encryption. A distinguishing feature of Aur0ra is its stealthy approach: it does not change the filenames or extensions of the files it encrypts, making it harder for users to immediately identify the scope of the damage. Victims are directed to a Tor-based site for negotiation via a ransom note.
- [Actively Exploited Microsoft Defender Flaws Allow Privilege Escalation, Evasion](https://cyber.netsecops.io/articles/microsoft-defender-vulnerabilities-actively-exploited-in-the-wild/) (critical)
  Two vulnerabilities in Microsoft Defender are being actively exploited in the wild, prompting CISA to add them to its Known Exploited Vulnerabilities (KEV) catalog. The flaws, CVE-2026-41091 (Elevation of Privilege, CVSS 7.8) and CVE-2026-45498 (Denial-of-Service, CVSS 4.0), allow attackers to gain SYSTEM-level permissions or disable the antivirus engine, creating a window to deploy malware undetected. Users are urged to ensure their Microsoft Defender Antimalware Platform is updated to version 4.18.26040.7 or later.
- [New 'Underminr' Flaw in CDNs Puts 88 Million Domains at Risk of Evasive Attacks](https://cyber.netsecops.io/articles/underminr-cdn-vulnerability-exposes-88-million-domains-to-domain-fronting-attacks/) (high)
  A newly disclosed vulnerability named 'Underminr' affects shared Content Delivery Network (CDN) infrastructure, enabling a sophisticated form of domain fronting. The flaw allows attackers to hide malicious command-and-control (C2) traffic behind an estimated 88 million trusted domains, primarily impacting infrastructure in the U.S., UK, and Canada. By placing a legitimate domain in the unencrypted part of an HTTPS request, attackers can bypass security tools and route traffic to a malicious server, a technique already being exploited in the wild and expected to be amplified by AI-driven malware.
- [Laravel-Lang Supply Chain Attack Injects Credential Stealer into 233 Package Versions](https://cyber.netsecops.io/articles/laravel-lang-supply-chain-attack-compromises-over-200-package-versions/) (high)
  A major supply chain attack has targeted the popular Laravel-Lang project, used for language localization in the Laravel PHP framework. Attackers compromised 233 version tags across three key repositories, injecting a multi-stage credential-stealing payload. The attack cleverly exploited a GitHub feature, allowing malicious version tags to point to a forked repository, thereby bypassing direct code commits to the official project. The package manager Packagist served the compromised code, which fingerprinted infected machines and downloaded a second-stage payload from a C2 server to steal a wide array of credentials.
- [Packagist Supply Chain Attack Uses Clever Evasion to Infect PHP Projects with Linux Malware](https://cyber.netsecops.io/articles/coordinated-packagist-attack-infects-php-projects-with-linux-malware/) (high)
  A coordinated supply chain attack has compromised at least eight packages on Packagist, the main PHP package repository. The attackers modified the packages to download and execute a Linux binary hosted on GitHub. In a clever evasion tactic, the malicious code was hidden in the `package.json` file, which is typically used for JavaScript tooling, rather than the expected PHP `composer.json` file. This allowed the `postinstall` script to evade security scanners focused on the PHP ecosystem. The Packagist team has since removed the malicious versions.
- [Critical Unauthenticated SQLi Flaw in Drupal Core Hits PostgreSQL Sites](https://cyber.netsecops.io/articles/critical-sql-injection-vulnerability-cve-2026-9082-in-drupal-core-for-postgresql/) (critical)
  The Drupal project has released security updates to patch a critical SQL injection vulnerability, tracked as CVE-2026-9082. The flaw affects Drupal Core sites that use a PostgreSQL database backend. It can be exploited by an unauthenticated, anonymous user, making it extremely dangerous for any public-facing site. Successful exploitation can lead to data disclosure, privilege escalation, and potentially remote code execution (RCE). Drupal administrators using PostgreSQL are urged to update their sites immediately.
