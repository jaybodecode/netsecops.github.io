Dairy Queen Operator Fourteen Foods Discloses Data Breach

Fourteen Foods, a large operator of Dairy Queen Grill & Chill restaurants, has disclosed a data breach that exposed sensitive personal information, including names and Social Security numbers. The breach occurred in February 2026 when an unauthorized party accessed the company's network. Impacted individuals were notified in October 2026, eight months after the initial intrusion was detected, highlighting significant delays in the incident response and notification process.

Panzer Ransomware Group Claims Attack on IT Firm Yodingenierie

The Panzer ransomware group has claimed responsibility for a cyberattack on Yodingenierie, an IT and engineering company based in Benin and a member of the pan-African NED&CO Group. The breach was discovered on October 25, 2026. This incident highlights the continued global reach of ransomware gangs, targeting organizations of all sizes and sectors, including in developing regions.

Article Updates

SoftBank Cloud Unit Crippled by Ransomware, 495 Orgs Affected

Update:Further investigation into the IDC Frontier ransomware attack revealed that while no evidence of large-scale data exfiltration was found, attackers did access and view registration records for 48 customers. These records included sensitive information such as login IDs, hashed passwords, and notification email addresses. This new detail indicates a direct compromise of customer credentials, posing a risk of subsequent phishing or credential stuffing attacks against the affected organizations. The incident continues to highlight the cascading impact of cloud service breaches.

ConnectWise Disables Cloud Services After Supply Chain Attack on M365

Update:New information reveals that Microsoft has attributed the ConnectWise Cloud Backup supply chain attack to the threat actor group Storm-0940. This group leveraged a compromised application credential to gain unauthorized access to 173 Microsoft 365 customer and partner environments between October 15-16, 2026. Attackers were observed attempting to establish persistence within compromised tenants by adding new credentials to other trusted applications, a technique identified as T1098.001 (Additional Cloud Credentials). This update reinforces the critical nature of the incident and provides specific threat actor attribution, highlighting the ongoing risk of third-party application compromises in cloud environments.

LiteLLM Supply Chain Attack Steals Cloud and AI Service Keys

Update:New analysis reveals attackers compromised LiteLLM's release pipeline using stolen GitHub CLI OAuth tokens from project engineers. The malicious package achieved persistence by modifying Python startup hooks (`sitecustomize.py`, `usercustomize.py`), ensuring execution whenever Python starts, not just on library import. Beyond credential harvesting, the malware also included a remote access trojan (RAT) backdoor. Microsoft and Datadog provided detailed technical analysis, confirming the sophisticated nature of the attack and updating detection guidance.

PHP2Shell Flaws Actively Exploited, Triggering Global Scramble

Update:New information regarding the PHP2Shell RCEs (CVE-2026-109618, CVE-2026-109619) confirms a CVSS score of 9.2. A critical warning highlights that PHP versions 8.1 and older are End-of-Life and will not receive patches, making systems running them permanently vulnerable and requiring immediate decommissioning or upgrade. The vulnerabilities, rooted in code from 2004, affect specific configurations like mod_php, PHP-FPM, and LiteSpeed. Expanded mitigation strategies now include network segmentation and reducing the attack surface. Response actions emphasize immediate host isolation and credential rotation upon suspected compromise.

Oracle's October CPU Delivers Record 1,295 Security Patches

Update:Further analysis of Oracle's October 2026 Critical Patch Update reveals that among the 95 critical vulnerabilities, six have been identified with a maximum CVSS score of 10.0. These flaws are particularly severe as they permit unauthenticated remote code execution, posing an extreme risk to affected systems. Specific products impacted by these CVSS 10.0 vulnerabilities include Oracle Access Manager, Oracle SOA Suite, E-Business Suite Workflow Notification Mailer, and JD Edwards EnterpriseOne Orchestrator. Additionally, a detailed breakdown shows Oracle Fusion Middleware, E-Business Suite, Communications, Siebel CRM, PeopleSoft, and JD Edwards as heavily impacted product families, with many remotely exploitable vulnerabilities.

GitLab Patches Critical CVSS 10.0 Unauthenticated RCE Flaw

Update:Further details on the critical GitLab RCE vulnerability (CVE-2026-110264) have emerged. Patched versions now explicitly include `18.11.13` and the latest releases in the `19.x` series, expanding on the previously mentioned `19.5.1`. Crucially, new 'Cyber Observables' have been provided to aid detection and hunting efforts. These include monitoring web server logs (Nginx, Puma) for unusual requests, observing GitLab processes (`gitlab-rails`, `gitaly`) for anomalous behavior, and using the `/-/health` URL pattern to enumerate GitLab versions across networks. These details offer more actionable intelligence for defenders.
