Widespread Microsoft 365 Outage Hits Millions of Users Globally

A significant global outage struck Microsoft 365 services on November 12, 2026, affecting Outlook, Teams, SharePoint, and Copilot. The disruption, which lasted for over 24 hours for some users, was caused by a large number of servers failing health checks, leading to a cascading failure across the infrastructure. Microsoft confirmed the incident was not a cyberattack and worked to restore services by restarting servers and rerouting traffic, though intermittent issues persisted as a massive email backlog was processed.

Belarusian Cloud Provider ActiveCloud Hit by Disruptive Ransomware Attack

Belarusian cloud provider ActiveCloud suffered a major ransomware attack on November 10, 2026, causing widespread outages for its customers. The attack encrypted parts of the company's cloud infrastructure, taking down its own website, customer support systems, and client services including virtual servers and corporate email. The disruption affected numerous businesses in Belarus and Russia, including news outlets and e-commerce sites. ActiveCloud worked for several days to restore its infrastructure and customer environments.

Unpatched 'SignDrop' Windows Zero-Day Allows SYSTEM Privilege Escalation

A security researcher has publicly disclosed 'SignDrop,' an unpatched zero-day vulnerability in the Windows Common Log File System (CLFS). The flaw allows a local attacker to escalate privileges to NT AUTHORITY\SYSTEM. The exploit cleverly abuses a security mitigation Microsoft introduced in 2025 to harden CLFS, turning the defense mechanism into an attack vector. A proof-of-concept exploit has been released on GitHub, affecting recent versions of Windows 11 and Windows Server 2025. Microsoft has not yet assigned a CVE or released a patch.

'Neutrino' Ransomware Discovered Using Double-Extortion Tactics

Security researchers have identified a new ransomware family named 'Neutrino.' This malware follows the double-extortion trend, where it not only encrypts a victim's files—appending a '.neutrino' extension—but also claims to have exfiltrated sensitive data before encryption. The attackers leave a ransom note, 'README-RECOVERY.txt,' threatening to leak the stolen data if the ransom is not paid. This tactic is designed to increase pressure on victims to pay, even if they have viable backups.

Critical Flaws in Red Hat Quay Enable Full Registry and Supply Chain Attack

Red Hat has patched two critical vulnerabilities in its Quay container registry, CVE-2026-123710 (CVSS 9.8) and CVE-2026-110697 (CVSS 9.9). These flaws could allow an attacker to achieve a full supply chain compromise by injecting malicious container images. The vulnerabilities enable an unauthenticated attacker to gain read/write access to any repository or a low-privileged user to steal tokens and manipulate images across tenants. All users of Quay 3 and 5 are urged to patch immediately.

China-Nexus Group Uses Autonomous AI Framework for Cyber Espionage

Between August and September 2026, a China-nexus threat actor tracked as CL-STA-1238 conducted a sophisticated campaign using an open-source AI penetration testing framework called Cairn. The attackers targeted at least 19 organizations across the semiconductor, defense, and civil society sectors in 25 distinct, autonomous operations. By weaponizing Cairn with large language models like Zhipu GLM and DeepSeek, the actor was able to automate reconnaissance, exploitation, and data retrieval, successfully breaching at least 10 of the targeted entities. This activity represents a significant evolution in cyber operations, leveraging autonomous agents for intelligence collection with minimal human intervention.

Massive GitHub Supply Chain Attack Injects 'wfx' Stealer into Repos

Update:The GitHub supply chain attack, now dubbed 'wfx-loot', has escalated significantly. Over 4,800 GitHub accounts were compromised, impacting at least 1,835 repositories, including those of Fortune 100 companies, the US General Services Administration, and the French government. Attackers are now known to steal OIDC tokens in addition to other cloud credentials. New TTPs include using 'docs: dependency audit notes' for reconnaissance and exfiltrating data via Telegram. The campaign also led to the infection of a Packagist package and a Go module, demonstrating broader supply chain compromise.
