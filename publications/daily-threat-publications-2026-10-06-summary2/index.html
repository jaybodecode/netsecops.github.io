Atlassian Patches Critical File Access Flaw in Jira and Confluence

Atlassian has issued security updates for a critical arbitrary file access vulnerability, CVE-2026-21589, which carries a CVSS score of 9.3. The flaw affects eight of its Data Center and Server products, including Jira, Confluence, and Bitbucket. An unauthenticated attacker could exploit this vulnerability to access specific files within an application's web root directory. While exploitation requires prior knowledge of the file's name and path, Atlassian urges customers to patch immediately due to the risk of sensitive information exposure.

Denmark's National Population Register Breached, 8.8M Records Exposed

Danish authorities have disclosed a massive data breach affecting the country's Central Person Register (CPR), exposing the personal information of 8.8 million people. The breach was not caused by a software vulnerability but by attackers misusing the legitimate credentials of a private company authorized to access the database. The compromised data includes names, addresses, and the highly sensitive 10-digit CPR numbers, creating a significant risk of identity theft and fraud for a large portion of the Danish population. An investigation is underway, and the third-party's access has been revoked.

Georgia Power Data Breach Exposes Information of 300,000 Customers

Georgia Power has disclosed a data breach that exposed the account information of approximately 300,000 customers. The incident, which also impacted its parent company, Southern Company, involved an unauthorized third party gaining access to the online customer portal. Exposed data includes customer names, addresses, phone numbers, email addresses, and the last four digits of their Social Security numbers. The utility has secured the portal and notified law enforcement.

CISA Warns of Critical Flaws in IoT, EV Charging, and Access Control

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) has issued multiple advisories for vulnerabilities across several IoT and OT platforms. These include missing authorization flaws in the Meari IoT Cloud Platform, a critical 9.4 CVSS vulnerability in the Monta EV-charging platform that could allow station impersonation, and several bugs in the Armatura One access control system that could lead to arbitrary code execution. CISA is urging users to patch where possible and reduce network exposure for these systems.

Microsoft Patches High-Severity Exchange Privilege Escalation Flaw

Microsoft has released an out-of-band security update for a high-severity privilege escalation vulnerability in Microsoft Exchange Server, tracked as CVE-2026-96940. The flaw, rated 8.8 CVSS, could allow an authenticated attacker to gain unauthorized access to other users' mailboxes within the same tenant. While there is no evidence of active exploitation, Microsoft has assessed the vulnerability as 'Exploitation More Likely.' The patch has been automatically applied to Exchange Online, but on-premises customers must install the update manually.

IBM & Red Hat's "Lightwell" Initiative Fixes 400+ Java Vulnerabilities

IBM and Red Hat have announced a major milestone for their Lightwell initiative, revealing that the project has identified and fixed over 400 previously unknown vulnerabilities in widely used open-source Java libraries. This effort, part of a $5 billion commitment to secure the software supply chain, now includes the general availability of the Lightwell Clearinghouse service. This service allows enterprise customers to submit dependencies for priority security review and receive backported patches, enabling them to secure older software without full upgrades.

"ClingSTUN" Botnet Exploits IoT Devices Using STUN Protocol for C2

A new botnet malware, dubbed 'Cling' or 'ClingSTUN,' is actively compromising a wide range of IoT devices like routers and DVRs by exploiting multiple vulnerabilities. A key feature of the malware is its use of the STUN (Session Traversal Utilities for NAT) protocol for its command-and-control (C2) communications, a technique that helps it blend in with legitimate network traffic and evade detection. Once infected, devices are used as proxy nodes for further malicious activities, including DoS attacks. The botnet is observed exploiting numerous flaws, including a critical RCE in the Realtek Jungle SDK.

Iranian Actor Targets Iraqi Infrastructure with "Blinder Tunnel"

Unit 42 has detailed a sophisticated cyber-espionage campaign, named "Blinder Tunnel," orchestrated by an Iranian state-aligned threat actor (CL-STA-1178). Active since at least March 2026, the campaign targets critical infrastructure in Iraq by impersonating the Dubai Airports IT department in a fake recruitment process. Attackers lure targets, primarily software engineers, into downloading a trojanized coding challenge. This initiates a multi-stage infection chain deploying custom malware called ShelbyLoader V2. The operation is notable for its use of the GitHub API for command-and-control (C2) communications to evade detection, a technique known as living-off-the-cloud. The actor also employs emerging evasion techniques like AppDomainManager hijacking. Analysis revealed operational security failures by the attackers, which allowed researchers to link this activity to another campaign targeting an Israeli entity.

Citrix Patches Critical NetScaler Zero-Day Under Active Attack

Update:Citrix has provided an updated and more comprehensive list of patched versions for CVE-2026-88779, now including NetScaler ADC and Gateway 13.0-92.21 and later, as well as NetScaler ADC 12.1-FIPS and 12.1-NDcPP 12.1-55.302 and later. This expands on the previously reported 14.1 and 13.1 updates. Additionally, security firm WatchTowr has successfully reproduced the denial-of-service (DoS) attack, further confirming active exploitation of the vulnerability. While RCE potential remains under investigation, the confirmed DoS impact is significant.
